## 一句话背景

AE 对 relay 是**原样透传**：不改请求体（除鉴权头）、不重试、不切换候选。代价是 AE 看不到中间那一层做了什么——回执协议（echo）就是补这个洞：让 relay 把「我真正发给上游的东西」回传，AE 落库留证。
